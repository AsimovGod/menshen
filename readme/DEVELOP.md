## 开发文档
所有主要函数、变量命名皆遵循大驼峰命名法。开头两字母为类型标识符，名称中只允许英文字母。

### 命名规范
#### 函数
```c
void
FvFunction()
{
}
```
函数以 `F` 开头。
- 第二个字母表示输出类型（如 `void` 标注为 `v`）。

#### 结构体
```c
struct SdDeclaraction {
};
typedef struct {
} StTypedef;
typedef struct SaAlias {
} SaAlias;
```
结构体声明以 `S` 开头。
- `Sd` 表示常规声明，只能通过 `struct SdDeclaraction` 的形式使用；
- `St` 表示无标签的隐式 `typedef` 声明，只能通过 `SdDeclaraction*` 的形式使用；
- `Sa` 表示声明别名，可以同时使用 `Sd` 和 `St` 的形式使用。

#### 标量变量
```c
int DiData;
```
标量变量以 `D` 开头。
- 标量变量只存储单个值。
- 第二个字母表示变量类型，（如 `int` 表示为 `i`）。

#### 一维数组
```c
char* AcArray;
```
一维数组以 `A` 开头。
- 数组只有一维，存储的所有值变量类型相同；
- 第二个字母表示变量类型，（如 `int` 表示为 `i`）。

#### 多维数组
```c
char** TcTable;
```
多维数组以 `T` 开头。
- 数组在一维以上，存储的所有值变量类型相同。
- 第二个字母表示变量类型，（如 `int` 表示为 `i`）。

#### 基础指针
```c
void* PvVoid;
```
基础指针以 `P` 开头。
- 基础指针是指除数组外其他基于标准库定义的指针，可能包含不同类型的值。
- 第二个字母表示典型指代，（如 `void*` 表示为 `v`）。

#### 自建指针
```c
SaAlias CsCustom;
```
自建指针以 `C` 开头。
- 自建指针是指使用自建结构体或其他自建方式定义的指针。
- 第二个字母表示典型指代，（如自建结构体表示为 `s`）。

#### 附加指针
```c
GtkWidget* EgExtra;
```
附加指针以 `E` 开头。
- 附加指针是指基于三方库定义的指针。
- 第二个字母表示典型指代，（如gtk库表示为 `g`），非固定，视具体环境。


### 节点图
节点图指本项目用于在函数中传递变量一组自建数据体，方便在不建立全局变量的情况下传递值。
- “节点”指自建结构的内部标签，“合集”指同一自建结构内所有节点的总称；
- 将未设计下级合集的节点称为末端节点，非末端节点采用大驼峰命名法，末端节点采用小驼峰命名法；
- 同一合集内可以为某一节点创建附属节点，命名包括被附属节点名与末尾全大写属性标记。
- 此图表仅包含采用自建数据体生成的末端节点，不包括其他方式创建的节点。
- [`Sa`] 表示结构体声明命名，实际命名替换为 [`Cs`]
